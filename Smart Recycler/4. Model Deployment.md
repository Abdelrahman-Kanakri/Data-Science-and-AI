  Function labels the 30 classes to match model output
  returns: A dictionary of labels

- creates a DataFrame that links "Class Name," "Category," and "Labeled Classes" for easier lookup.
```python
def Categories_df(series1, series2):
    categories = pd.DataFrame({
        "Class Name": series1.keys(),
        "Category": series1.values(),
        "Labeled Classes": [series2.get(name, None) for name in series1.keys()]
    })
    return categories
```

- Loads images, preprocesses them, and uses ResNet50 to classify them.
- Results are mapped to categories and printed for each image.
```python
def predict_images_from_folder(folder, resnet, cats):
    """
    Predicts the class, class name, and category for all images in a specified folder.

    Parameters:
    - folder (str): Path to the folder containing images.
    - resnet: The pre-trained ResNet model for making predictions.
    - categories (pd.DataFrame): DataFrame containing "Labeled Classes", "Class Name", and "Category".

    Returns:
    - results (list): A list of dictionaries containing image name, predicted class, class name, and category.
    """
    # Collect all files from the folder
    image_files = [f for f in os.listdir(folder) if os.path.isfile(os.path.join(folder, f))]

    results = []

    # Iterate through each image
    for img_file in image_files:
        image_path = os.path.join(folder, img_file)

        # Load and preprocess the image
        img = image.load_img(image_path, target_size=(224, 224))
        img_array = image.img_to_array(img)
        img_array = np.expand_dims(img_array, axis=0)
        img_array = preprocess_input(img_array)

        # Make the prediction
        predictions = resnet.predict(img_array)
        predicted_class = np.argmax(predictions, axis=1)[0]  # Extract single prediction

        # Look up class name and category from the DataFrame
        class_name = categories[categories["Labeled Classes"] == predicted_class]["Class Name"].values[0]
        category = categories[categories["Labeled Classes"] == predicted_class]["Category"].values[0]

        # Collect results for this image
        results.append({
            "image": img_file,
            "predicted_class": predicted_class,
            "class_name": class_name,
            "category": category
        })

        # Optionally print the result for each image
        print(f"Image: {img_file}")
        print(f"Predicted Class: {predicted_class}, Class Name: {class_name}, Category: {category}\n")

```
# Behavioral Consumer Analysis with DeepSeek-R1
- DeepSeek-R1 Model Setup:
  
    - `BitsAndBytesConfig` : Configures 4-bit quantization to reduce model size and improve performance.
    - `AutoTokenizer & AutoModelForCausalLM`: Loads the DeepSeek-R1 model and tokenizer.
- Model Inference Functions
    - `get_outputs`: Generates output predictions using the DeepSeek-R1 model based on user inputs.
    - `query_model`:

          - Formats input prompts to query DeepSeek-R1 for behavioral analysis.
      
          - Uses a creative prompt based on items predicted by ResNet50 (resnet_preds_test).
      
          - Output suggests how waste is generated and provides eco-friendly recycling tips.
- End-to-End Workflow:
    - `ResNet50 Prediction`: Classifies images into waste categories.
    - `DeepSeek-R1 Analysis`: Uses the classified items to analyze behavioral patterns, environmental impact, and suggest recycling strategies.

def get_outputs(model, inputs, max_new_tokens=200):
    outputs = model.generate(
        input_ids=inputs["input_ids"],
        attention_mask=inputs["attention_mask"],
        max_new_tokens=max_new_tokens,
        repetition_penalty=1.1,
        early_stopping=True, #Can stop before reach the max_length
        eos_token_id=tokenizer.eos_token_id,
        pad_token_id=tokenizer.pad_token_id,
        do_sample=False
    )
    return outputs

def query_model(system, user_input, max_new_tokens = 200):
  messages = [{"role": "system",
                "content": system},
                {"role": "user",
                "content": user_input}
                ]

  prompt = tokenizer.apply_chat_template(messages, tokenize=False, add_generation_prompt=True)

  #Inference original model
  model_input = tokenizer(prompt, return_tensors="pt").to('cuda')

  foundational_outputs_sentence = get_outputs(model, model_input, max_new_tokens=max_new_tokens)
  output = tokenizer.batch_decode(foundational_outputs_sentence, skip_special_tokens=True)
  return output
