# Code Documentation

## General Purpose Libraries
- **os**: Provides functions for interacting with the operating system, such as file and directory management.
- **shutil**: Provides file operations like copying, moving, and deleting files and directories.
- **pandas**: A powerful library for data manipulation and analysis, especially for tabular data.
- **numpy**: A fundamental library for numerical computations, used for arrays, matrices, and mathematical functions.
- **matplotlib.pylab as plt**: A plotting library for creating static, animated, and interactive visualizations.

## Image Processing Libraries
- **PIL (Pillow)**: Python Imaging Library (PIL), now maintained as Pillow, used for image processing tasks.
- **cv2**: OpenCV library for computer vision tasks such as image and video analysis.
- **glob**: Used for filename pattern matching and retrieving files with specific patterns.
- **IPython.display**: Enables the display of rich media such as images in Jupyter Notebooks.

## Machine Learning Libraries

### TensorFlow and Keras
- **tensorflow**: A popular open-source framework for machine learning and neural networks.
- **tensorflow.keras.layers as tfl**: Keras layers in TensorFlow, providing building blocks for neural networks.

#### Layers from `tensorflow.keras.layers`:
- **RandomFlip**: A layer that randomly flips images horizontally during training for data augmentation.
- **RandomRotation**: A layer that randomly rotates images within a specified angle range during training.
- **RandomZoom**: A layer that applies random zoom to images during training for data augmentation.
- **RandomContrast**: A layer that randomly changes the contrast of images during training for data augmentation.

- **tensorflow.keras.utils.image_dataset_from_directory**: Utility function to load image datasets from directories.
- **tensorflow.keras.preprocessing.image.ImageDataGenerator**: A class for real-time image data augmentation and preprocessing.
- **tensorflow.keras.applications.ResNet50**: ResNet50, a pre-trained model for image classification.
- **tensorflow.keras.applications.vgg16.preprocess_input**: Function to preprocess input for the VGG16 model.

### Keras Models
- **keras.models.Sequential**: A linear stack of layers in a neural network.
- **keras.models.Model**: General class for defining neural network models.

#### Layers from `keras.layers`:
- **Conv2D**: Convolutional layer for feature extraction from images.
- **MaxPooling2D**: Max pooling layer to reduce dimensionality and capture key features.
- **Flatten**: Flattens input for feeding into fully connected layers.
- **Dense**: Fully connected layer for classification or regression.
- **Dropout**: Regularization layer that randomly drops a fraction of inputs during training to prevent overfitting.
- **BatchNormalization**: Normalizes activations between layers to improve training efficiency and stability.
- **GlobalAveragePooling2D**: A pooling layer that computes the average of each feature map in 2D convolutional layers.
- **Rescaling**: Rescaling layer that normalizes input images (e.g., dividing by 255).

- **keras.callbacks.EarlyStopping**: Callback to stop training early if the model performance doesn't improve.
- **keras.applications.vgg16.VGG16**: VGG16, another pre-trained model for image classification.
- **keras.utils.image_dataset_from_directory**: Utility to load image data in batches from directories.
- **keras.Input**: Specifies an input layer for a neural network.
- **tensorflow.keras.regularizers.l2**: L2 regularization to penalize large weights and prevent overfitting.
- **tensorflow.keras.optimizers.Adam**: Adam optimizer for gradient-based optimization of the model's weights.
- **tensorflow.keras.losses.CategoricalCrossentropy**: Loss function for multi-class classification problems.

## Warnings
- **warnings**: Used to manage warning messages in Python.
- **warnings.filterwarnings("ignore")**: Disables all warnings (useful when you want to ignore unnecessary warnings).
